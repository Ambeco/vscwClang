Gotchas: (1) `wasm-wasi-core` `extensionLocation` mounts need `dir-dump` listings (`<path>.dir.json`) and, even with them, clang's include search dropped `/sysroot/include/wasm32-wasip1` as a "duplicate directory" and later headers resolved wrongly (likely identical stat identities in that mount); fixed by mounting the sysroot as `memoryFileSystem` populated from `sysroot.zip`. (2) memory FS paths have no leading slash for `createFile`/`createDirectory`, and parent dirs must be created first. (3) Pass `-fno-color-diagnostics -fno-caret-diagnostics` or stderr chunks interleave illegibly. (4) Output `-v` shows the include search list; use it for header problems. Dev loop: `npx vscode-test-web --browser=none --coi --extensionId=ms-vscode.wasm-wasi-core --extensionDevelopmentPath=. --port=3000 .`, then F1 `vscwClang: Probe`.
